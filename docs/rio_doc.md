### 4.5 异常处理

Rio 支持 `try` / `catch` / `finally` / `throw` 四个关键字。

```rio
fun safeDivide(a, b) {
    if b == 0 {
        throw "division by zero"
    }
    ret a / b
}

try {
    sout(safeDivide(10, 0))
} catch(e) {
    sout("出错了：")
    sout(e)
} finally {
    sout("清理")
}
```

规则：

- `throw` 后面跟一个表达式，该值就是异常值；抛出后 `throw` 之后的语句不再执行。
- `catch(e)` 把异常值绑定到变量 `e`，`e` 只在 catch 体内可见。
- `finally` 无论是否发生异常都会执行；`catch` 与 `finally` 至少写一个。
- 只写 `finally` 不写 `catch` 时，`finally` 执行完异常继续向外层传播。
- 异常会跨函数传播，直到被某一层 `catch` 接住；无人接住时程序以退出码 3 终止。

当前实现的限制：

- `catch` 没有类型匹配，只有 `catch(e)` 一种写法；写多个 `catch` 时只有第一个生效。
- 异常值按字符串处理，请用 `throw "消息"`；抛非字符串值的后果未定义。
- 非局部退出不保证执行析构（当前版本本来也没有析构）。

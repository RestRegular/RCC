# RCC 更新日志

## 变更类型与版本号对应关系
| 变更类型           |   缩写    |  对应版本层级  | 说明                                       |
|:---------------|:-------:|:--------:|:-----------------------------------------|
| **Breaking**   |  break  |  Major   | 不兼容的API变更或功能调整，可能导致旧版本生成的文件/代码无法在新版本中运行  |
| **Feature**    |  feat   |  Minor   | 向后兼容的功能新增或模块扩展，不影响现有功能的正常使用              |
| **BugFix**     |   fix   |  Patch   | 向后兼容的问题修复，解决已知的功能缺陷或错误                   |
| **Optimize**   |   opt   |  Patch   | 性能优化相关修改，不影响现有功能逻辑和接口                    |
| **Deprecate**  |  depr   |  Minor   | 标记即将在未来版本中移除的功能，当前仍保持兼容性并提供替代方案          |
| **Refactor**   |   ref   |  Patch   | 代码结构重构，不改变功能行为和对外接口，仅优化内部实现              |
| **Docs**       |   doc   |  Patch   | 仅文档内容更新（如README、注释、使用说明等），无代码逻辑变更        |
| **Test**       |  test   |  Patch   | 测试相关修改（如新增测试用例、优化测试代码等），不影响生产代码功能        |

## 规则备注

采用 `Markdown` 中划线（`~~...~~`）格式标注的版本号（示例：~~v1.0.0~~），特指该版本的 Release 在运行时，所输出的版本号存在偏差；当前已完成修正，最新有效版本号以新标注内容为准。

### 版本号 `v1.24.0` (2026-11-20)
- **类型**：**[Feature] [Docs] [Test]**
- **作者**：RestRegular
- **更新时间**：2026/11/20 08:31
- **更新内容**：
  - **[Feature]** 内存模型规范补强收尾，补齐 P13-6/P13-7 已批规范内的可落地项（提交 `ec20a4d`，18 文件 +481/-34）：
    - **snapshot 成员登记**：`take`/`release` 时把成员集合登记进 snapshot，支持后续活跃性判断。
    - **成员集合活跃性**：统计成员时排除已出作用域的死变量，避免把无效引用计入。
    - **循环动态加入重数饱和**：循环体内动态加入的元素按 `many` 饱和，重数格 `ZERO/ONE/MANY/TOP` 计算更保守。
    - **嵌套展平传递闭包**：成员集合沿 `groups→team→a` 多级嵌套做传递闭包展平，不再只展平一层。
    - **`dict.clone()`**：新增字典浅拷贝原语 `core_clone_dict`，与 `str`/`list`/标量的 `clone()` 派发打通。
    - **`set` 旧对端自动移除**：`core_link_set` 建立新边前先清除两端的旧边，再 `add` 新边，避免残留对偶边。
  - **[Docs]** `docs/p12_plan.md` 过时状态订正；`p13_6_syntax_audit.md` / `p13_7_syntax_audit.md` 状态回填；`pending_designs.md` 明确登记剩余设计空白为「推迟、须另立提案」（G1b argv、规范 §12 未决 1–13、输出引用 API、§11.1 状态放宽、容器元素递归释放、`*@L`/闭包捕获/函数边界、物理 `links_nonempty` 位图、§7.5 实例级迭代冲突）。
  - **[Test]** 新增 `L3-dict-clone`、`p13-6-pool` 五条（snapshot/活跃性/循环 many/嵌套展平）、`p13-7-link` 一条（set 旧对端），全量 40 套件 1035 用例全绿。

### 版本号 `v1.23.0` (2026-11-20)
- **类型**：**[Feature] [Docs] [Test]**
- **作者**：RestRegular
- **更新时间**：2026/11/20（提交 `d26e111`，89 文件 +6061/-278：13 个 `code/`、2 个 `lib/core`、9 份文档、65 个测试文件）
- **更新内容**：
  - **[Feature]** 完整实现并验收结构化并发（`memory-model-spec-full.md` §10 全章）：
    - **`scope` / `spawn`**：作用域内任务 + 末尾隐式 join；每任务一个 OS 线程（1:1），任务句柄为二等值，只接受具名顶层函数（Q1–Q3）。
    - **效果集并行冲突检查**：由实参能力推导 `R/W/S/L` 效果，两两不冲突才允许并行；借出变量在 scope 内对父线程冻结；跨函数全局/extern 触碰汇总分析（Q13），Q4/Q13/G1–G4 全部落地。
    - **`par_each` 数据并行**：自带 join、成员集合快照语义、禁止 Link 遍历（Q5/Q18）。
    - **`Locked<T>` / `lock` / `Atomic<T>`**：二等值不逃逸、同锁重入编译期拒绝、不 poison；`Atomic` 最小集 `i32`/`i64` 顺序一致（Q6/Q7）。
    - **`Chan<T>` 通道**：独立标准库类型、显式 close、scope 结束自动关闭、有界容量、`T?` 关闭语义（Q8）。
    - **`at()` 安全窄化**：无效槽返回 `ptr?`，必须 `if var` 窄化后使用，消除解引用崩溃。
    - **粒子系统两阶段示例**：按 Q5=C/Q19 以 `par_each` + 只读捕获另一类型 Pool + `at(id)` 落地，阶段间由 scope join 分隔。
  - **[Docs]** 规范 §10.8 改为 par_each 两阶段 Rio 形态；§10.9 补 happens-before 同步点条文；新增 `p14_plan.md` + 6 份实施方案 + 设计审计文档。
  - **[Test]** 新增 7 套 P14 测试（`p14-1a-thread`、`p14-1b-scope-spawn`、`p14-2`/`p14-3`/`p14-4`/`p14-5`、`p14-6-acceptance`、`p14-final`）；全量 40 套件 1028 用例全绿。已知限制仅剩死锁/活锁不在静态保证、Chan 退避轮询非 futex、关闭时残留 Content 泄漏（均为规范原有声明）。

### 版本号 `v1.22.0` (2026-11-17)
- **类型**：**[Feature] [Refactor] [Breaking]**
- **作者**：RestRegular
- **更新时间**：2026/11/17 01:50
- **更新内容**：
  - **[Breaking]** 删除旧 RA 后端全部路径。RA 虚拟机、RA 指令发射、内置函数注册表
    （`rcc_builtin_*_functions.cpp`）、DLL 扩展机制（`IRCCSymbolInterface` /
    `bindDllExt` / `unbindDllExt`）一并移除。新后端直接发射 x86-64 GAS 汇编。
  - **[Breaking]** 删除 `-ir` / `--ir-o` 选项。LLVM 中间码不再是产物，
    编译一步到位：`RCC -build --path in.rio --output out`。
  - **[Breaking]** 标准库整体重写为 `lib/std/*.rio` 六个模块（唯一真相，
    构建时拷贝到 `release/Lib/builtin/`）：
    - `ds`（22 个）：保留 15、新增 `map`/`filter`/`contains`/`indexOf`/`reverse`/
      `slice`/`concat`/`sum`，删除 `unpack`/`iterContains`/`iterRemove`/`joins`/`iter`
    - `str`（15 个函数 / 22 个重载入口）：`toChar`/`intToChar` 返回值类型变更，
      `toLowerCase`/`toUpperCase` 只接受 `str`
    - `math`（7 个）：`abs`/`max`/`min`/`opp`/`pow` + 常量 `pi`/`e`
    - `ops`（4 个）：`ternary`/`ternaryLazy`/`orVal`/`orLazy`
    - `io`（2 个）：`input`/`sin`
    - `prog`（2 个）：`entry`/`breakpoint`
  - **[Breaking]** 删除 `datatype` 模块（整模块）；`lowlevel` 模块整体裁掉
    （`id`/`rasm`/`ri`/`bindDllExt`/`unbindDllExt` 全部不提供）。
  - **[Feature]** 补齐 11 项语言能力缺口：G1a 顶层 `var` 全局槽、G2 索引赋值
    （`a[i]=v` / `d[k]=v` / `a[i]+=v` / `a+=[v]`）、G3 `str + str`、G4 列表拼接、
    G5 方法重载、G7 `ret` 字段访问、G9 `str` 比较、G10 `s[i]` 读取、
    G11 方法链、G12 `ptr` 同族放宽、G13 `ptr`↔`int` 互转。
  - **[Feature]** `-s` 符号表导出器重写，支持六种格式
    （`text` / `json` / `html` / `ctags` / `dot` / `markdown`），新增 `-exp`
    只列导出符号。
  - **[Feature]** 新增 `-emit-lib` 库模式（不发射 `main`，用于编译标准库）。
  - **[Refactor]** `scripts/run.bat` 从 LLVM 五步流水线改为一步编译，
    路径从脚本自身位置推导，不再写死 `D:\ClionProjects\...`。
  - **[Refactor]** `scripts/test.bat` 退化为薄壳，判定逻辑统一收敛到
    `test_scripts/test_all.ps1`（旧版用 `fc /W` 比对，会吞掉空白差异，
    与 `test_legacy_all.ps1` 的逐字节比对语义冲突）。
  - **[BugFix]** 修复浮点字面量被截断到 6 位有效数字：`doubleToString` 改用
    `std::to_chars` 最短往返表示。修前 `3.141593` 存成 `3.14159`、
    `sout(pi)` 打印 `3.141589`；修后正确。
  - **[BugFix]** 修复 `str` 为 `null` 时字符串运算段错误：
    `emitStrConcat`/`emitStrEq`/`emitStrOrder` 直接读长度头未判空，
    `"" + null` / `null == ""` / `null < "a"` 全部崩溃（exit `-1073741819`）。
    新增 `emitContainerLenTo()` 统一按「`null` 长度 0」处理。
  - **[BugFix]** 修复 `ds.top([])` 对 `str` 返回野指针：空列表分支的
    `var zero: T = xs[0]` 读了未初始化的堆内存，改为 `var zero: T`。
  - **[BugFix]** 修复 `ds.join` 单独 `import ds` 时无法编译：`join` 依赖
    `str.toStr` 但 `ds.rio` 未 import `str`，已补上。
  - **[Docs]** `docs/p12_plan.md` 补 §10.6（P12-3-D 三层验收落地记录）与

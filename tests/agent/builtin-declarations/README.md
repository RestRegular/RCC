# builtin-declarations 套件

验证内建声明体系（2026-11-20 改造 + 严格化裁决）：

- 内建/原语可直接调用（sout/serr/clone/size/get 等，声明由隐式前导自动加载，无需用户声明）
- 特化内建/core 原语必须有 Rio 源码声明（标签区 builtin/extern）；调用点惰性校验，缺声明则硬错误
- 声明标签与返回类型/子句顺序无关
- 未声明函数编译期报错（不再拖到链接期）
- core_*/rt_* 运行时原语合法
- 用户不得给保留名写真实函数体（旧 encapsulated 桩已移除，改用无体声明）
- 用户自定义同名非内建函数（如 release）不受误伤

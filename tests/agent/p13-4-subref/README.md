# P13-4 子引用与局部排他 回归套件

对应规范 `docs/memory-model-spec-full.md` §4，裁决见 `docs/p13_4_syntax_audit.md` §3。
9 个用例，覆盖 Q1–Q3 三项落地：

- **Q1 多级字段路径登记**：`&p.team.captain.name` 精确登记为完整路径，
  §4.1 前缀冲突判据对多级路径生效（深路径精确相等 / 祖先写 / 中间写均报冲突；
  不相交字段放行）。
- **Q2 字段复合赋值**：`p.hp += 10` 等五种 int 运算 + float 四种运算正确运行；
  写回复用 §4.1 冲突检查（持 `&p.hp` 时 `p.hp += 1` 报冲突）。
- **Q3 写效果函数体推断**（§4.3）：函数未写 `writes` 标注时，编译器从函数体
  推断对形参路径的写；调用点据此与活跃子引用做冲突检查（写 `p.name` 拦住，
  写不相交的 `p.score` 放行）。

`dict.clone()` / 容器递归释放经 Q4 裁决归 P13-6，不在本套件。
